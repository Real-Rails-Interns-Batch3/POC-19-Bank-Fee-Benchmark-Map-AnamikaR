# Bank Fee Benchmark Dashboard

A Real Rails fintech intelligence dashboard for benchmarking banking fees geographically using live financial data.

## Features

* FastAPI Backend
* Next.js Frontend
* Interactive Map Visualization
* Live Financial Data Support
* Fee Benchmark Analytics
* Dynamic Filtering
* Download Sample Data
* Real-time Dashboard UI

## Project Structure

backend/

frontend/

README.md

VAR_REPORT.md

UAT_CHECKLIST.md

## Backend Setup

cd backend

python -m venv venv

Activate:

Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run backend:

uvicorn main:app --reload

Backend:

http://127.0.0.1:8000

## Frontend Setup

cd frontend

npm install

npm run dev

Frontend:

http://localhost:3000
